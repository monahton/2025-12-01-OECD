Detailed Setup

Algobank

You will need an account at gitlab.algobank.oecd.org for parts of the Git lesson. Check if you can connect to your account prior to the workshop. In case your account is not activated, please let the organizers know prior to the workshop. Please bring the device you are using for two factor authentication (2FA) to the workshop.

Text editor

In this course we will work with text files, so you will need a text editor installed on your system. Please install Notepad++ from the OECD Software Center.

VSCode

For code development using an integrated development environment (IDE) provides comprehensive support. In this workshop we will be using VSCode. Please install VSCode version 1.105 or higher from the Data Science Toolkit in the OECD Software Center.

Git

Git is a version control system that lets you track who made changes to what when and has options for easily updating a shared or public version of your code on servers like github.com, gitlab.com or the OECD-hosted gitlab.algobank.oecd.org. Please install Git version 3.5.1 from the Data Science Toolkit in the OECD Software Center.

Python

Python is a popular language for research computing, and great for general-purpose programming as well. Please install Python-3.12 from the Data Science Toolkit in the OECD Software Center. To benefit from Python support also within VSCode, please install the Python extension in VSCode.

Jupyter

We will teach Python using the Jupyter Notebook, a programming environment that runs in a web browser. We will use Jupyter Notebook within VSCode. To activate support for Jupyter within VSCode install the Jupyter extension.

Python project setup and environment

We will work in a dedicated project workspace in this workshop. This way you will be able to work on different projects using different configuration and depending on different Python dependencies without interference between projects. To create a project workspace

  • Create a folder in your local filesystem that will contain the project: `C:/SmartData/Carpentries`
  • Open VSCode and open the newly created folder using the `File` > `Open Folder` dialog
  • Add the requirements.txt file to the project folder
  • Create a dedicated Python environment for this project:
    • Click on the search bar on the center top of the VSCode window, select `Show and Run Commands (Ctrl + Shift + P)`
    • In the search menu type `Python: Select Interpreter` > `+ Create Virtual Environment` > `Venv` and select the global Python installed via the Software center at `~\AppData\Local\Microsoft\WindowsApps\python3.12.exe`
    • VSCode will recognize the `requirements.txt` file and ask you if the dependencies should be installed in the new environment. Confirm this and click `Ok`. VSCode will take a few seconds to setup the environment and install the dependencies.
    • Once the installation is complete, VSCode will confirm that the new environment is now in use for the project. The created environment is stored in a newly created `.venv` folder in the project.
